# Temvorax

> Plataforma de organização da vida acadêmica, profissional e pessoal de estudantes universitários.

## Sobre o projeto

O Temvorax é um projeto desenvolvido durante a graduação em Ciência da Computação na Unochapecó.

Seu objetivo é criar uma plataforma capaz de integrar a organização da vida acadêmica, profissional e pessoal dos estudantes universitários em um único ambiente.

Além do desenvolvimento do software, o projeto busca documentar toda a evolução técnica da plataforma, desde a pesquisa inicial até sua implementação.

---

## Objetivos

- Centralizar informações acadêmicas, profissionais e pessoais.
- Auxiliar na organização da rotina universitária.
- Aplicar conceitos de Engenharia de Software e Desenvolvimento Mobile.
- Documentar a evolução do projeto durante a graduação.

---

## Tecnologias previstas

- Kotlin
- Android Studio
- SQLite + Room
- Firebase Authentication
- Git & GitHub
